# Steering Committee Decision Log

This is a running index of Steering Committee votes on public business, maintained under the [Decision Log](charter.md#decision-log) section of the Steering Committee Charter.

Steering Committee votes on public business are [required to be captured on a GitHub issue or pull request](charter.md#voting). Each row below links a decision to the issue or pull request where it was made and recorded, so the reasoning behind past decisions stays traceable as committee membership turns over.
